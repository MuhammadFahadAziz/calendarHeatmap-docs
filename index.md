# Calendar Heatmap

Calendar Heatmap is a Power BI custom visual for displaying daily values in a month-by-month calendar layout.

## Links

- Privacy Policy: [privacy.md](./privacy.md)
- Support: [support.md](./support.md)
- Visual source repository: <https://github.com/MuhammadFahadAziz/calendarHeatmap>

## Overview

Calendar Heatmap helps report authors visualize day-level values in a familiar calendar layout with interactive month and day selection, formatting controls, and Power BI report filtering support.
